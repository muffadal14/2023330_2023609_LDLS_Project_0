## Caveats

* Answers stop after 24 generated tokens (`-n 24`), so they end mid-sentence. That is the budget, not a fault: a fixed budget keeps the before/after comparison the same length for every document, and an answer does not have to be a finished sentence to be provably unchanged.
* The comparison uses top logits rather than text. Removing KV cells changes the CPU reduction order, so a greedy choice can flip without the context changing; a different context moves the logits by whole units, noise by hundredths.

Generated by `tests/make_slide.py` from `results/experiments.json` and the parser output, so the numbers cannot drift from the run they describe.
